# Flask Student Management System

A web-based Student Management System developed using Flask, SQLite, Jinja2 templates, and Bootstrap.

## Project Overview

This project demonstrates the development of a Flask mini web application with routing, GET and POST form handling, SQLite database storage, and complete CRUD operations.

## Features

- Add new student
- View all students
- Edit student details
- Delete student records
- SQLite database storage
- GET and POST request handling
- Jinja2 template rendering
- Responsive Bootstrap user interface
- Delete confirmation before removing a record

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- Jinja2
- Bootstrap 5.3.3
- VS Code
